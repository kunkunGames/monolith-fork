💡 What
Add `TArray::Reserve(Symbols.Num())` before filtering source symbols in `MonolithSourceActions.cpp`.

🎯 Why
When parsing source lines and class hierarchies, the server copies elements from the `Symbols` array into the `Filtered` array inside loops. Pre-allocating capacity prevents multiple underlying array memory re-allocations during iteration.

📊 Impact
Static/algorithmic estimate: Reduced memory re-allocations from $O(\log n)$ per filter loop to $O(1)$ single allocation upfront.

🔬 Measurement
Static estimate.
