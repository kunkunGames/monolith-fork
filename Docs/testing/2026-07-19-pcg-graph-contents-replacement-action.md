# PCG Complete Graph Contents Replacement Verification

**Date:** 2026-07-19
**Status:** Source, schema, focused automation, spec, and skill implemented; GraphContents 4/4 automation, live schema, and downstream canonical graph verification complete; protected linked build and aggregate suite pending
**Changelist:** 1198

---

## 1. Scope

Add `pcg.replace_pcg_graph_contents` for promoting an already-authored project-owned donor `UPCGGraph` into an existing canonical target without changing the target package, object path, or live UObject identity. The action replaces complete donor-owned persistent graph state instead of replaying a partial node loop or overwriting `.uasset` bytes. CL1198 does not mutate ProjectMGH or any other gameplay/content asset; the later owning content changelist has now completed and independently verified the initial ProjectMGH parent-graph integration.

## 2. Engine/API proof

| Gate | Result | Evidence |
|---|---|---|
| Existing-target duplication | PASS (source inspection) | UE 5.8 `FObjectDuplicationParameters::DuplicationSeed` explicitly maps a source object to an existing destination that is not duplicated. `StaticDuplicateObjectEx` serializes the source root and referenced inner objects into that destination while `GatherDefaultSubobjectsForDuplication` pairs the source/target `DefaultInputNode`, `DefaultOutputNode`, their settings, and default pins. Because the duplicate stream is archetype-delta serialized, Monolith first resets every duplicable property on the reusable target root and every source-relative inner object matched by the complete outer/name/class lineage to its exact archetype value; a source/default value can therefore replace a stale non-default destination value without a field-specific fallback, while unmatched target-only editor objects remain untouched. The source and target inner sets are each enumerated once and joined by an indexed relative-lineage key instead of recursively rescanning the global UObject array for every graph inner. |
| Arbitrary inner references | PASS (source inspection) | Seeded whole-object duplication uses one source-to-destination annotation map, so settings references between nodes, named-reroute declaration/usage links, embedded subgraphs, graph parameter hierarchy objects, pin/edge subobjects, and other reflected inner references are remapped together. `UPCGGraph::ReconstructNewNode` remains appropriate for isolated nodes but is intentionally not used for this whole-graph contract because independent duplication cannot guarantee arbitrary cross-node reference remapping. |
| Target identity | PASS (implementation gate) | Source and target must be distinct exact clean project-owned assets with concrete class exactly `UPCGGraph`. The source root is seeded to the existing target root. The action records and verifies target outer, name, path, class, and pointer identity after preview/apply; raw package overwrite, rename, redirector, alias, case-only path, subclass, and source-equals-target paths fail closed. Root `UPCGGraphInterface::LastEditedDocuments` is target-owned editor workspace state, so the action snapshots and preserves the target value rather than importing donor document paths. |
| Persistent completeness | PASS (implementation gate) | The comparator indexes each graph-owned UObject once by complete root-relative outer/name/class lineage, then serializes each `ShouldDuplicateValue()` property once through a package-persistent archive with graph-owned hard references normalized to those identities and external references retained as exact object paths. Persistent archive semantics make nested structs follow UE `ShouldSerializeValue`: `Transient` and deprecated runtime/cache members are generically excluded, while editor-only values that package saving retains are still compared. The sole explicit ownership exception is target-root `UPCGGraphInterface::LastEditedDocuments`, which is excluded from donor/target comparison and preserved through preview, commit, rollback, save, and reload; this does not permit a broader node-, pin-, or type-specific skip, and all donor-owned persistent properties remain exact. The generic archive corrects the observed false mismatch at `PCGPin.Properties`, whose `bAllowEditMultipleData` and `bAllowEditMultipleConnections` members are reflected transient editability caches, without a pin-specific skip; a persistent `PinStatus` difference in the same struct still fails exact comparison. Every reachable inner-object pair is visited once; the old recursive `PPF_DeepComparison` path is prohibited because shared/cyclic node, pin, edge, and settings references caused repeated pair expansion on a historical 561-node donor snapshot. `UserParameters` retains its exact persistence-aware ordered descriptor comparison and now uses the same canonical non-recursive value serialization. UE 5.8 reconstructs the transient `UPropertyBag` script-struct type from serialized descriptors, so its pointer identity may legitimately differ after duplicate/save/reload and is not treated as persistent state. Any descriptor, value, reflected persistent property, owned-object identity, external reference, or native-property difference still fails exact read-back. The target's native node delegates are rebound through `PreNodeUndo`/`PostNodeUndo`, then a structural/settings/edge/input/grid notification invalidates compiler/runtime caches. |
| Bounded destructive gate | PASS | `dry_run` defaults true and builds then structurally validates the same replacement in a transient duplicate. Commit requires both `dry_run=false` and `confirm=true`. `node_limit` and `edge_limit` bound source and target at the module maxima (5,000/20,000); persistent comparison independently fails closed above 250,000 inner objects, 256 outer levels, or 128 MiB of serialized property payload per side. A structurally invalid or already-recursive source, and a donor hierarchy that contains the target, are rejected before preview. Dirty source/target packages are rejected rather than silently discarding unpersisted state. |
| Source control | PASS (implementation contract) | The action is registered as handler-owned source control. Default/explicit dry-run and exact unchanged requests return structured skips and never call checkout. A real changed commit invokes the shared `FMonolithSourceControlUtils::CheckoutOrAddPackage` for the exact target after validation/no-op gates and immediately before snapshot/mutation, consistent with existing PCG component actions. Final numbered-changelist validation remains an operator/integration gate. |
| Rollback | PASS (implementation gate) | Before mutation the target is duplicated to a transient rollback snapshot and all existing transactional inners call `Modify`. Apply/read-back/identity/structural-validation/test-fault/save failure restores complete state through the same archetype-baselined seeded path, including graph-level defaults, empty/original `UserParameters`, topology, target-owned `LastEditedDocuments`, and the original package dirty bit; bounded canonical persistent equality verifies the donor-owned graph state before the action reports `rollback_status=verified`. An incomplete restore reports the exact first mismatch in `rollback_error` and leaves the target dirty. |
| Save and idempotence | PASS (implementation gate) | `save=true` uses the existing `UEditorAssetSubsystem::SaveLoadedAsset` plus non-empty package-file requirement. The bounded canonical persistent-object comparator checks a transient preview against the target before mutation; an exact repeat returns `unchanged`, `saved=false`, and performs no source-control prepare or save. |
| Static source preflight | PASS | The local UE 5.8 EngineSource index reports schema/FTS/CRG integrity healthy with no maintenance required. `source.lint_header` reports no findings for `MonolithPCGGraphAuthoringActions.h`; direct engine-header reads confirm the public `UPCGGraphInputOutputSettings::AddPin`, graph default-pin accessors, non-deprecated `GetObjectsWithOuter(..., EGetObjectsFlags)`, and editor undo node-detach pattern used here. |
